# Pitfalls: Roblox Studio
## The "20k Triangle" Trap
Roblox validates mesh topology on import. If you join 5 meshes together, you get one massive blob.
**Rule:** Every object in the root `Model` should ideally be its own `MeshPart`.
**Fix:** Use `thrixel_group_parts` to split the mesh by semantic material (Paint, Glass) before export.

## The "Floating Island" Issue
Roblox can be forgiving with pivots, but if you rotate the whole model root, the parts might spin around the center.
**Solution:** Set the pivot of every `MeshPart` to its local origin before grouping.

## Texture Resolution
Roblox textures are "rough." 2k maps are fine, but 4k maps on a small rock look like static.
**Target:** 1024x1024 for standard assets, 512x512 for environment details.

## The "Pending" Limbo
Uploaded assets pass through moderation. They might show up in the catalog but look black in the game.
**Agent Tip:** Always run a "Bake Textures" step or force a refresh in the UI script if the agent is in a headless loop.

-- A self-checking Lua script for the agent to verify its work.
-- Place this in Roblox Studio 'ReplicatedStorage' or Model root
local function InspectMesh()
	local model = script.Parent
	local valid = true
	local warnings = {}

	-- Check every child MeshPart
	for _, child in ipairs(model:GetDescendants()) do
		if child:IsA("MeshPart") then
			local mesh = child.Mesh
			if mesh then
				local polyCount = child:GetAttribute("PolygonCount", 20000) -- Fallback attr
				-- Logic to handle the 'MeshQuality' property
				if child.MeshQuality == "Low" then
					table.insert(warnings, string.format("%s has %s triangles", child.Name, polyCount))
				end
			end
		end
	end

	-- Log report for the coding agent
	print("Roblox Import Inspect:")
	for i, w in ipairs(warnings) do
		print(w)
	end
end
