# Thrixel Build World for ChatGPT

Describe a game and get a playable 3D browser game back, with a link you can share.

Build World plans the game, generates its 3D models with [Thrixel](https://thrixel.com)
(game-ready .glb files you own), writes the game in three.js, and publishes it to a public
`https://<name>.thrixel.world` address that anyone can open in a browser, phone included.

Everything runs on Thrixel's servers. There is nothing to install: add the plugin, connect
your Thrixel account when ChatGPT asks, and ask for a game.

## Try it

- "Build a submarine exploration game in three.js set in a bright tropical sea."
- "Make me a game-ready 3D model of a wooden treasure chest."
- "List my published Thrixel games."

## What it can do

- Generate, edit, detail and retexture 3D models, and reduce them to a triangle budget.
- Build a three.js game around those models, with keyboard and touch controls.
- Publish the game to a public link, and later update, rename or unpublish it.

## Usage

Generating models uses the Cubes on your Thrixel account. You can see your balance anytime in
your Thrixel account settings.
